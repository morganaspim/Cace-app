# Offline Math Objects and Metamaterial Search

CACE treats physical equations as typed math objects before they become claims. A canvas object may carry an equation, geometry family, target qualities, and validation requirements, but this metadata is not evidence by itself.

## Offline-only AI boundary

The Granite/Phi/Qwen group must operate with `LOCAL_ZERO_CONTACT` network mode. The models may inspect structured canvas state, selected objects, local capability metadata, local experiment history, and CACE result summaries. They must not browse the internet, call remote services, or import remote evidence.

The GUI may use approved APIs to import objects into the local workspace. Remote scientific imports, such as AlphaFold metadata, are explicit GUI/backend actions and must not be exposed as unrestricted AI tools. If an imported object enters the canvas, it remains an attributed external object. It is not CACE proof evidence and does not establish formal qualification.

AI canvas play is user-gated. When the option is off, the local AI group may suggest experiments but cannot build or manipulate geometry/algebra objects. When the option is on, the local AI group may play with local math objects and geometry, still with no network access and no evidence authority.

## Equation-backed physical objects

The first local templates are:

- hydrogenic atom: `\hat H\psi = E\psi`
- harmonic molecular bond: `V(r)=\frac{1}{2}k(r-r_0)^2`
- hexagonal tight-binding lattice: `H=-t\sum c_i^\dagger c_j + \sum V_i c_i^\dagger c_i`
- photonic crystal wave operator: `\nabla\times(\mu^{-1}\nabla\times E)=\omega^2\epsilon E`
- phononic mass-spring lattice: `M\ddot u + K(\theta)u=0`

These objects can be rendered, transformed, selected, animated, and queued for energy or optimization work. Any numerical result, spectrum, low-energy fold, or metamaterial quality requires a canonical CACE module and evidence pipeline.

## Metamaterial hypothesis workflow

The local search ranks candidate families from offline templates:

1. high-contrast photonic crystal
2. re-entrant auxetic lattice
3. topological edge-mode lattice

Each candidate records target qualities, governing equation, geometry family, why it might work, and the validation modules still needed. This is a prioritization aid, not a discovery claim.

## Color convention

- pink: quantum orbitals / atom-like objects
- amber: molecular bonds / local energy wells
- emerald: lattices / graph Hamiltonians
- cyan: wave and photonic geometry
- violet: mechanical/phononic geometry
- blue: protein or biological structure objects
- slate: coordinate frames

The color layer helps Qwen and the user scan geometry quickly. Color is a UI cue only; it is not evidence.

## RSI constraint

Recursive self-improvement is allowed only as a proposal loop:

AI proposes an object, tool, proof obligation, optimization, or code rewrite. CACE validates schemas, tests, graph compatibility, computation, proof linkage, and evidence promotion. Lean or other formal systems may discharge proof obligations where available. No model can directly make its own proposal canonical.
