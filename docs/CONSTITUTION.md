# CACE Studio Constitution v1.0

1. Every computation is a Module.
2. Every module is independently testable.
3. Every module documents assumptions, inputs, outputs and limitations.
4. Every computational claim names its evidence: symbolic, numerical, interval-certified, formally verified, or experimental.
5. Every experiment is reproducible from serialized inputs, module versions and dependency metadata.
6. AI is optional and never required for execution or verification.
7. Python orchestrates; native code performs justified heavy computation.
8. Every plugin follows the versioned SDK contract.
9. Public APIs are versioned and compatibility is tested.
10. No feature is marked implemented until its acceptance tests pass.
11. Failed or unavailable verification is visible, never converted to success.
12. Scientific honesty outranks feature count.
