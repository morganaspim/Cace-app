# Millennium-Scale Tool Extension, Novel Coordinates, and Physical Atom Canvas

CACE should approach Millennium-scale mathematics by extending canonically verified tools, not by treating AI conjectures or visual patterns as proof.

## Ranked extension routes

1. Certified PDE stack for Navier-Stokes regularity experiments.
2. Gauge-field lattice certificates toward Yang-Mills mass-gap experiments.
3. Interval/symbolic proof lab for Riemann zeta zero experiments.
4. Symbolic geometry objects for Hodge-cycle exploration.
5. Proof-complexity and circuit object lab for P versus NP.
6. Arithmetic geometry workbench for Birch and Swinnerton-Dyer evidence.

Each route starts from proof-backed CACE modules, then creates a next canonical tool with explicit proof obligations and Lean/export linkage where available. None of these are claimed solutions.

## Coordinateless math objects

Math objects enter CACE as typed, coordinateless objects. Placement on a canvas chooses a representation, not the object's identity. The same object should eventually support Cartesian, polar, molecular, Gaussian `i`, Eisenstein `omega`, fractal tile-address, and cellular heartbeat displays.

## Conway-inspired heartbeat geometry

The Life heartbeat view is a research visualization where cells at different sizes pulse as local clocks or scale layers. It can help Qwen and the user see multi-scale structure, but it is not evidence until connected to canonical graph/computation modules.

## Physical atom canvas

The GUI exposes a periodic-table seed palette. Selecting an element places an attributed atom object into the molecular canvas with atomic number and valence hints. The AI group may manipulate atoms or propose molecules only when `AI canvas play` is enabled. Internet/API imports remain GUI/backend actions; the AI group remains `LOCAL_ZERO_CONTACT`.
