# ADR 0011 — General 2D reliability envelope and theorem registry v2

v0.9 separates two statements. First, a general-mesh, exact-solution-free *run certificate* is computationally discharged by combining a certified stability error envelope with a certified residual-estimator lower bound. Its resulting C_rel is run-specific. Second, the desirable mesh-uniform residual-reliability theorem remains an obligation-only formal artifact.

Theorem Registry v2 records structured premises, scope, status, required evidence, and artifact provenance. Registry presence never upgrades evidence to formal verification.
