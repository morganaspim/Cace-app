# ADR 0027 — Ranked CACE roadmap v1.51–v2.0

The 50-release program follows ten ranked tracks, five releases per track:
RT1 flux; global P2; enriched DWR; robust heterogeneous guarantees; AFEM theory integration;
mixed methods; spectral bounds; parabolic certification; FEEC/Maxwell structure; and v2
proof/capability integration.

Ordering is deliberate: each later track reuses earlier numerical and evidence infrastructure.
Reviewed mathematics remains REVIEWED_ASSUMED and is never silently promoted to formal evidence.
