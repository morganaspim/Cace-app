# ADR 0027 — v1.51–v2.0 ranked maturity roadmap

The 50-release sequence follows ten ranked tracks, five releases each:

1. RT1 / higher-order equilibrated flux
2. Production global P2 FEM
3. PDE-level goal-oriented DWR
4. Robust heterogeneous/data-oscillation guarantees
5. Adaptivity theorem integration
6. Mixed / saddle-point methods
7. Verified spectral bounds
8. Parabolic / time-dependent certification
9. FEEC / Maxwell-compatible complexes
10. v2.0 integration / evidence architecture

The ordering is by expected scientific leverage from the v1.50 baseline, not by novelty.
Reviewed mathematics remains reviewed; exact finite-dimensional fixtures remain symbolic/exact;
numerical diagnostics remain numerical; no category is silently promoted.
