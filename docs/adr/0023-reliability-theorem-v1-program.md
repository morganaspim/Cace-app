# ADR 0023 — Reliability theorem development through v1.0

v0.77–v1.0 deliberately separates finite-dimensional exact identities, run-specific certificates, reviewed analytic assumptions, and unresolved family-uniform theorems.

The v1.0 milestone MUST NOT promote the general 2D conforming P1 residual reliability theorem while any of these remain open:

- all-H1 quasi-interpolation local estimate,
- all-H1 trace estimate in the required patch form,
- mesh-family-uniform finite-overlap bound tied to the admitted shape-regular family.

Exact edge orientation, affine Green identities, and residual edge bookkeeping are useful closed sublemmas but are insufficient by themselves to prove the continuum theorem.
